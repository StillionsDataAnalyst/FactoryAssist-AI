# 90-Day Pilot Plan

## Scope

- One production line
- 10–20 equipment assets
- 20–50 approved reaction plans
- Existing SOPs and equipment manuals
- Operators, maintenance technicians, and one plant champion

## Baseline measures

- Average time to find the correct procedure
- Average time to escalate an issue
- Average response time
- Repeat issue count
- User confidence and adoption

## Pilot outcomes

- Faster access to approved procedures
- More consistent reaction plans
- Better issue documentation
- Identification of repeat failures and training gaps

## Governance

- Plant personnel approve all reaction plans.
- Safety-critical answers always include escalation.
- AI responses cite approved source documents.
- Usage is reviewed weekly during the pilot.
